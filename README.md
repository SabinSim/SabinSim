## 🚀 Projects

### German Study App
`C#` `.NET` `Avalonia UI` `EF Core` `SQLite` `OpenAI API`

A desktop spaced-repetition trainer for German vocabulary, built to fix a real frustration: constantly having to ask *why* a noun takes a certain article, or how an adjective ending shifts with context.

- Leitner-system flashcards with 4-level review grading, leech detection, and undo
- AI generates an example sentence for every saved word, with on-demand grammar analysis (verb forms, cases, article/gender reasoning)
- Nested decks with drag-and-drop hierarchy, bulk `.txt` import, EF Core Migrations for schema changes, and a unit-tested Core layer
- Every line in the `Core` and `Infrastructure` layers written by hand; UI built with AI assistance to move faster

### LinguaAI — AI Language Companion
`C#` `ASP.NET Core 10` `Blazor Server` `OpenAI TTS` `GPT-4o mini` `Azure`

A web app for practicing German, Korean, and English, built after moving to Switzerland and getting frustrated with inaccurate machine translation and slow, unfocused LLM chat for language practice. [Live demo](https://tts-web-app-sabin.azurewebsites.net) · [Repo](https://github.com/SabinSim/tts-web-app)

- Text-to-speech with natural-sounding audio (multiple voices, adjustable playback speed) via OpenAI TTS
- Instant translation between German, Korean, and English using GPT-4o mini
- AI chat tutor for practicing real conversations, with replies read aloud automatically
- Deployed on Azure App Service

I write every line myself. AI is my teacher, not my ghostwriter — it explains a concept, I ask questions until it clicks, then I write the code.
